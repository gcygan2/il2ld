Program przetwarza plik wejściowy <nazwa>.il zawierający program w język IL
buduje reprezentację graficzną programu w języku LD i zapisuje do pliku tekstowego <nazwa>.ld

Przykład
1. Tworzymy plik zawierający program w języku IL i zapisujemy w pliku program.il
2. W wierszu poleceń (cmd)
`il2ld program`
